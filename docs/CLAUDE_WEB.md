# إضافة المكتبة إلى Claude Web

دليل الإضافة من واجهة Claude على المتصفح، باستخدام **Add marketplace** وليس أوامر Claude Code.

## الرابط المستخدم

أضف مستودع الفورك العام:

```text
https://github.com/osa822630-droid/code-animation-prompts
```

أو صيغة الاسم المختصر:

```text
osa822630-droid/code-animation-prompts
```

يجب أن تكون ملفات الـmarketplace موجودة على فرع **`main`** في هذا الفورك. لا تستخدم رابط المستودع الأصلي `XiaoyeCodes/code-animation-prompts` لهذه الإضافة؛ حزمة الويب موجودة في الفورك.

## خطوات الإضافة

1. افتح Claude على الويب، ثم **Customize → Plugins**.
2. اضغط **Add → Add marketplace → Add from a repository** حسب ترتيب القائمة الظاهر في حسابك.
3. الصق رابط الفورك أو صيغة `owner/repo` بالأعلى، ثم أكِد الإضافة أو المزامنة.
4. بعد ظهور الـmarketplace، أضف plugin باسم **Code Animation Prompts**. إضافة الـmarketplace وحدها لا تعني أن الـplugin اتثبت.
5. افتح محادثة جديدة وجرّب الأمر المختصر:

```text
/code-animation-prompts:animate B3، مدخل 12 ثانية عن تحويل الفكرة إلى واقع، مقاس 16:9، جزيئات ذهبية على خلفية داكنة.
```

يمكن بدلًا من الأمر كتابة طلب طبيعي مثل: «استخدم code-animation-prompts واقترح لي نمطًا مناسبًا لفيديو شرح عن المطر». اسم الـskill الكامل داخل القائمة هو `/code-animation-prompts:code-animation-prompts`.

لو ظهرت خيارات تشغيل الملفات، فعّل **Code execution and file creation** أو **Create and edit files** من إعدادات القدرات. قراءة مكتبة الأنماط وإنشاء HTML تعتمد على الأدوات المتاحة في جلسة Claude؛ تثبيت الإضافة لا يضمن وجود Playwright أو FFmpeg لتصدير MP4.

## ماذا تتضمن حزمة الويب؟

- 341 ملف أنماط كاملًا.
- 193 صورة مرجعية، و148 نمطًا بمرجع نصي فقط.
- فهرس البحث وأداة البحث بلغة Python.
- منتقي الأنماط الذي يعمل دون اتصال، وأمثلة HTML واللقطات والتراخيص.
- أمر `/code-animation-prompts:animate` لتسهيل الاستدعاء.

فيديوهات MP4 الثلاثة الكبيرة غير مكررة داخل حزمة الويب لتقل حجمها. الملفات الأصلية باقية في [المكتبة الكاملة](../skills/code-animation-prompts/assets/library/示例)، وطرق التثبيت المحلية الأصلية لم تتغير.

## ملاحظات الحساب والخطط

ملفات هذا المستودع لا تطلب مفتاح API ولا تشغّل خدمة خارجية مدفوعة، ولا تفرض خطة حساب. ظهور **Add marketplace** وإتاحة تثبيت وتشغيل الـplugins يتحكم فيهما Claude وإعدادات الحساب والسياسات الحالية. قد تختلف إتاحة الخاصية بين الحسابات أو أثناء طرحها؛ مستودع GitHub لا يستطيع تجاوز قيود المنصة. لذلك نجاح الفحوص المحلية يعني صحة الحزمة، ولا يُعد اختبارًا داخل حسابك.

## لو الإضافة أو المزامنة فشلت

- تأكد أنك تستخدم الفورك `osa822630-droid/...` وليس المستودع الأصلي.
- تأكد أن التعديلات وصلت إلى `main`، وأن المستودع ما زال عامًا.
- يجب أن يوجد الملف [.claude-plugin/marketplace.json](../.claude-plugin/marketplace.json) في جذر الفرع الافتراضي.
- مصدر الـplugin يجب أن يظل المسار النسبي `./plugins/code-animation-prompts` داخل نفس المستودع؛ لا تستخدم مسارًا خارجيًا أو `npm`.
- لو أضفت نسخة قديمة قبل وجود الملفات، اعمل مزامنة للـmarketplace أو احذف إضافتها القديمة وأعد إضافتها.
- لو ظهر الـplugin لكن الـskill غير ظاهر، افتح محادثة جديدة، وتأكد من تفعيل الإضافة وقدرات تشغيل الملفات المتاحة لحسابك.
- لو ظهرت رسالة تعارض اسم marketplace، راجع هل أضفت مستودعًا آخر بنفس اسم `code-animation-prompts` من قبل.

## للمطورين: فحص الحزمة

لا يحتاج المستخدم النهائي إلى أي من هذه الأوامر. بعد تعديل الـskill الأصلي:

```bash
python scripts/build_web_plugin.py
python scripts/build_web_plugin.py --check
python scripts/validate_repo.py
```

الأمر الأول يحدّث نسخة الويب من المصدر الأصلي. الأمر الثاني يتحقق من التطابق بدون كتابة. الثالث يفحص الروابط وسلامة الملفات الأصلية وتعريفات الـmarketplace والـplugin. توجد الحزمة الناتجة داخل Git عمدًا لأن Claude يقرأها مباشرة من GitHub ولا يشغّل خطوة build.
